SIEM use cases from the GPU rack to the agent layer

A detection library for AI GPU data centers. Each use case gives the log source to collect, a sample log for building parsers and testing rules, and detection logic mapped to MITRE ATT&CK, MITRE ATLAS and OWASP. Coverage runs from identity and the network edge, through the GPU fabric, bare metal, Kubernetes and schedulers, up to model serving, LLM applications, RAG and the facility itself.

Sources: MITRE ATT&CK (Enterprise & ICS), MITRE ATLAS, OWASP Top 10 for LLM Applications 2025, OWASP API Security Top 10 2023, and vendor logging documentation. Sample logs are synthetic. Hostnames, accounts, keys and IP addresses (RFC 1918 / RFC 5737 ranges) are made up, and fields are trimmed to what the detection needs. Field names follow each product's documented format where possible, but formats vary by version and collector, so check them against your own parsers before relying on a rule. Thresholds are starting points; tune them to your own baseline.
